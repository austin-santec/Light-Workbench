Light Workbench

ILM insertion-loss testing guide

Scope: This guide covers the normal hardware IL-reading workflow using the ILM/OP815 and switch. It does not cover the Red Light Test, Live IL Reading, or Repeatability Test tools.

1. Understand the main screen

Hardware test setup

  • Choose the channels and test mode.
  • Enter identifying information.
  • Set or calculate the 1310/1550 references.

Hardware controls

  • Start and stop the run.
  • Read, review, and write IL values.
  • Change channel or retest.
  • Copy completed readings for pasting into Excel.

Current readings

  • Shows the active channel.
  • Shows 1310 nm and 1550 nm IL.
  • Shows the next operator action.

2. Prepare the test

  1. Connect the equipment. Connect the ILM/OP815, the switch, and the fiber/cable arrangement required for the test. Make sure the approved USB driver and VISA setup are installed on the computer. If needed, use Tools > Check Dependencies... before starting.
  2. Open Light Workbench. Confirm that no other hardware run is active. The program normally opens in dark mode, but the appearance does not change the test process.
  3. Enter identifying information. Enter the part number, main board serial, and switch serial when available. The part number may be typed, selected from the list, or found with Lookup Part Number after entering the main board serial.
  4. Select the operating band. Choose O band or C band. This is recorded with the run.
  5. Set the warning limit. The Analysis panel defaults to 2.0000 dB. Change it if your test standard requires another limit. This limit flags and filters results; it does not prevent a reading from being written.

3. Calculate the reference

Recommended practice: Calculate the reference before every new switch test, using the normal reference connection for your station. New reference fields start at 0.00 dBm so the operator deliberately performs this step.
  1. Connect the reference path/cable used by your test procedure. Make sure the reference condition is stable before starting.
  2. Confirm the 1310 nm and 1550 nm reference fields are at the intended starting values, normally 0.00 dBm.
  3. Click Calculate Reference. A progress window appears while Light Workbench connects to the ILM and takes the reference measurement.
  4. Wait for the calculation to finish. The two reference fields are updated automatically, the progress window closes, and the ILM remote connection is released.
  5. Do not calculate a reference while a hardware run is active. If the reference must be changed, stop the run first.
Important: If the calculated values look unreasonable, stop and verify the reference connection, fiber seating, wavelength setup, and ILM state before testing the switch.

4. Choose the channel plan

ControlUse
Full configured passNormal mode. Light Workbench steps through the configured channel count in order and asks you to move the cable as needed.
Channel onlyTests one selected channel. The channel field appears when this mode is selected.
Channels / rangeTests a selected list or range, such as 1, 3, 7-10. The range field appears when this mode is selected.
Choose channel order manuallyOptional full-pass mode for scattered hardware. The program asks which channel to test next. Repeating a channel writes a replacement reading over the previous table value while retaining the attempt history.

5. Run the IL test

  1. Click Start Run. Confirm the hardware warning. Light Workbench connects to the OP815 and switch. In a full pass, it routes the first channel and displays a prompt such as Move cable, then read values.
  2. Move the physical cable. Connect the cable to the channel/port shown in Current readings. Confirm the channel number before measuring.
  3. Click Read IL. The button reads both wavelengths and displays them in Current readings. The keyboard shortcut is shown under the button; by default it is Return.
  4. Review the values. Confirm the channel, 1310 nm value, and 1550 nm value. Reading again is safe and does not write to the table. Use this if the cable was not seated correctly or you want to verify a result.
  5. Click Write IL. When the reading is acceptable, click Write IL or press its displayed shortcut, normally +. This commits the result to the table and run files, then advances the test.
  6. Repeat. Move the cable to the next requested channel and repeat the Read IL / review / Write IL sequence until the pass is complete.
Remember: Read IL measures only. Write IL saves and advances. If you read a value too early, simply read again before writing.

6. Correct the channel or retest

Change Channel...

Use this during an active run when the next physical cable/channel is not the one currently shown.

  1. Click Change Channel....
  2. Enter the channel number and confirm.
  3. Move the cable to the newly requested channel.
  4. Read and write the value normally.

In a sequential full pass, the program asks whether to continue from the selected channel or resume the interrupted channel afterward.

Retest selected

Use this after readings have been written:

  1. Select one or more rows in the results table.
  2. Click Retest selected.
  3. Move the cable when prompted, then Read IL and Write IL.

The latest accepted value replaces the displayed/table value. Earlier attempts remain available in the JSON history.

7. Read the table and analysis

AreaWhat it tells you
Current readingsThe channel currently being measured and its 1310/1550 nm IL values. A value shown here is not saved until Write IL is used.
Results tableSaved readings, one row per logical channel. Red/pink rows indicate that at least one wavelength exceeds the warning limit.
Show readingsFilters the visible table to all channels, within limit, any over limit, 1310 over, 1550 over, or both over. Filtering does not interrupt a run or change saved data.
AnalysisShows the total channel count and over-limit channel lists. For example, 2 (3, 7) means two channels—3 and 7—exceeded the limit.
Select Over-LimitSelects all currently displayed channels that exceed the warning limit so they can be retested together.

8. Finish and find the results

  1. Finish the pass or click Stop run. Completed written readings remain visible if the run is stopped early.
  2. Use the output files. Each saved run is stored under the configured IL-Reads output folder. The folder name includes the run date/time and available serial numbers. The CSV contains the table data and metadata; the same-named JSON contains run details and attempt history.
  3. Continue later if needed. Load the existing CSV with File > Open CSV Run... or the top-right button, then click Start Run. Choose to continue the loaded run when prompted.
  4. Optional COC. After a completed or stopped run, the program may offer to write a COC. This is separate from saving the IL measurements and can be skipped if not needed.
  5. Copy raw readings when needed. Click Copy Raw Data... in Hardware Controls to copy all written channel readings as tab-separated values for Excel. This includes only the logical channel, 1310 nm IL, and 1550 nm IL in channel order, without column headers so it can be pasted into an existing table. It ignores the table filter, excludes readings that were not written, and does not create another output file.

Quick operator checklist

1. Connect ILM/OP815, switch, and test cable. 2. Enter part number and serial information. 3. Select O band or C band. 4. Calculate Reference with the normal reference connection. 5. Choose the channel mode. 6. Click Start Run and confirm the hardware prompt. 7. Move cable to the displayed channel. 8. Read IL (Return) and review both wavelengths. 9. Read again if needed; nothing is saved yet. 10. Write IL (+) to save and advance. 11. Repeat until finished. 12. Use Change Channel or Retest selected when necessary. 13. Check the table filters and Analysis panel. 14. Stop/finish the run and confirm the CSV/JSON output.
